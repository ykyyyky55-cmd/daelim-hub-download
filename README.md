# 대림 허브 PC 앱 내려받기

대림 허브(대림오일 사내 업무 앱)의 윈도우 PC 앱 설치 파일입니다. 앱을 쓰려면 회사 계정으로 로그인해야 합니다.

- 최신 설치 파일: [daelim-hub-setup.exe](https://github.com/ykyyyky55-cmd/daelim-hub-download/releases/latest/download/daelim-hub-setup.exe)
- 설치 파일을 실행하면 설치되거나, 이미 있으면 새 버전으로 바뀝니다.
- 코드 서명 인증서가 없어 처음 실행할 때 Windows SmartScreen 경고가 뜹니다. `추가 정보` → `실행`을 누르세요.
